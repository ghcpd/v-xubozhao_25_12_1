Key justifications:

- scikit-learn: 0.24 → 1.x presents better performance and bug/security fixes; 1.7.2 selected for compatibility with numpy 2.x.
- pandas: 1.1 → 2.x is a big update with new dtypes & performance enhancements.
- pytest: 5.x is out of date; bump to pytest 9 to ensure compatibility with modern Python.
- FastAPI & Uvicorn updated to their modern releases for security and stability.
- SciPy & Matplotlib: upgrade to recent wheel-supported versions for modern Python.

Notes: I purposely pinned versions to exact releases for reproducibility. If you prefer a different reproducibility policy (loose ranges, freeze, or lock files), we can adjust.

## ⚠️ Important migration / compatibility notes
- scikit-learn 0.24 → 1.x: review code using specific `sklearn` internals or deprecated function names (transformer args, cross-validation changes, scoring).
- pandas 1.x → 2.x: re-check code that relied on older NA semantics and dtypes; new checks can cause warnings or errors.
- numpy 1.x → numpy 2.x: validate any code relying on dtype internals or extension arrays.
- pydantic / FastAPI: Pydantic v2 behavior changed key parts of model parsing/validation. If your API relies on older behavior, minor changes might be required.
