## Upgrade Justifications
- numpy: Modern numpy provides performance gains, thread-safety improvements and security patches; 1.18 is quite old and lacks features and optimizations introduced in later versions.
- scikit-learn: 1.x adds many new algorithms and bug fixes; 1.7 improves performance and is compatible with modern numpy.
- pandas: Upgraded to 2.x to maintain long-term support and compatibility with other libraries.
- matplotlib: Update for improved plotting and Python 3.13 compatibility.
- scipy: Newer SciPy provides bug fixes and improved compiled functions; 1.16.3 supports Python 3.13.
- pytest: 5.x is unmaintained; new pytest 9.x includes support for modern Python features and improved performance.
- fastapi & pydantic: Fastapi 0.123 is modern and uses pydantic v2 (2.12.5) — note pydantic v2 introduced some backwards-incompatible changes; our simple FastAPI usage does not rely on Pydantic v1-specific behavior.
- uvicorn: updated for ASGI spec compliance and security patches.

## Notes on Compatibility and Migration
- We tested the library interactions via pytest; all tests passed under Python 3.13.
- This upgrade uses `pydantic` v2 and `fastapi` versions compatible with it; if the project uses pydantic v1 specific constructs or relies on subtle behavior, additional code changes may be necessary.
- To minimize breaking changes for pandas API migration (1.x -> 2.x), additional test coverage should be added to the codebase focusing on pandas usage patterns.

## Recommended Next Steps
1. Run `pip-audit` and/or `safety` to scan for CVEs in installed packages.
2. Add CI steps to automatically run `setup.sh` and `run_tests.sh` in GitHub Actions / Azure Pipelines.
3. Migrate to a `pyproject.toml` and use `pip-tools` or `poetry` for finer reproducibility and dependency resolution.
4. Consider adding `--constraint` files or separate `requirements-dev.txt` for test-only dependencies.
